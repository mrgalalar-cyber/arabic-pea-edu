# المخطط التقني — منصة التعلّم العربية

> هذا المستند يسبق الكود: البنية، الخدمات، الحدود المجانية، المراحل، الصفحات، قاعدة البيانات، الصلاحيات.
> **النموذج المعتمد (آخر توجيه):** مالك واحد (`OWNER_EMAIL`) + معلمون يدعوهم المالك **برابط دعوة خاص**. المعلم المدعو يملك فصوله وطلابه وأسئلته وأنشطته ومراجعه وشهاداته فقط، ولا يرى بيانات غيره؛ والمالك يرى ويدير الجميع.

## 1) البنية المقترحة

| الطبقة | التقنية | السبب |
|---|---|---|
| الواجهة | React + TypeScript + Vite (تطبيق صفحة واحدة، RTL) | بناء ثابت يُستضاف على Netlify CDN، ويتوسع بسهولة |
| الحسابات | **Supabase Auth** (Google OAuth + مستخدمون داخليون للطلاب بالرمز) | يوفر Google جاهزًا، وجلسات JWT تعمل مع سياسات RLS |
| قاعدة البيانات | **Supabase Postgres** + سياسات Row Level Security | العزل والصلاحيات في قاعدة البيانات لا في الواجهة |
| الملفات | **Supabase Storage** (حاويات خاصة: صور، تسجيلات، صور الأسئلة) | روابط موقّعة مؤقتة، سياسات وصول |
| الخلفية | **Netlify Functions** (TypeScript) | كل ما يحتاج مفتاحًا سريًا أو تصحيحًا موثوقًا |
| المهام المجدولة | **Netlify Scheduled Function** يوميًا | حذف التسجيلات الصوتية فعليًا من التخزين بعد 3 أشهر |
| الذكاء الاصطناعي (مرحلة لاحقة) | Gemini عبر Netlify Function | المفتاح في بيئة الخادم فقط |

### لماذا Supabase وليس Firebase أو قاعدة أخرى؟
- Postgres علائقي مناسب للفصول والدرجات والتقارير (استعلامات تجميعية).
- سياسات RLS تجعل العزل مفروضًا حتى لو تلاعب أحد بالواجهة.
- Google Auth والتخزين في خدمة واحدة.

## 2) نموذج الأدوار والأمان

- **المالك**: بريده المُتحقق منه = `app_config.owner_email`، ويملك هوية Google ولا يملك هوية بريد/كلمة مرور (دالة `is_owner()` تقرأ JWT وجدول `auth.identities`) — يمنع انتحال بريد المالك.
- **المعلم**: صف في `teachers` يُنشأ حصرًا من الوظيفة الخلفية عند قبول دعوة (`teacher_invites`: رمز عشوائي 256 بت يُخزَّن مُجزَّأً، استخدام واحد ذرّي، صلاحية، تقييد اختياري ببريد Google، إلغاء). لكل صف في `classes` و`questions` و`learning_refs` عمود `teacher_id`، والفصل يحكم بقية الجداول (`owns_class()`).
- **العزل**: سياسات RLS: المعلم لا يرى/يعدّل إلا ما يخصه؛ حارس `activities_guard` يمنع إسناد أسئلة أو مراجع أو طلاب لا تخص معلم الفصل؛ أعمدة الهوية في `students` محجوبة عن المتصفح؛ الدرجات للقراءة فقط. اختبارات: `tests/rls.test.ts`.
- **الطالب (Google)**: مستخدم عادي، يصبح طالبًا فقط بعد موافقة المالك (ربط `students.auth_user_id`).
- **الطالب (رمز)**: عند الموافقة تُنشئ وظيفة خلفية مستخدم Supabase داخليًا (`student-<uuid>@students.invalid`) وكلمة مروره هي الرمز. الدخول عبر وظيفة `student-login` التي تحدّ المحاولات الخاطئة.
- **ضيف/منتظر**: لا صف في `students` ⇒ لا تصل سياسات RLS إلى أي محتوى.
- تعطيل تسجيل البريد/كلمة المرور في Supabase (Signups by email = off) حتى لا يستطيع أحد ادعاء بريد المالك.
- الدرجات تُحتسب وتُصحَّح **في الخادم** (`play-*`)؛ لا تصل الإجابات الصحيحة إلى متصفح الطالب قبل أن يجيب.

## 3) قاعدة البيانات (ملخص)

`app_config` · `teachers` · `teacher_invites` · `classes` · `students` · `join_requests` · `learning_refs` · `questions` · `activities` · `attempts` · `attempt_answers` · `audit_log` · `rate_limits` · `recording_tasks` · `recordings` (مجهّزتان للمرحلة 2).
التفاصيل الكاملة والسياسات في `supabase/schema.sql`.

## 4) خريطة الصفحات

**عامة:** `/` (اختيار الدور) · `/student/join` (طلب انضمام) · `/student/login` (رمز أو Google) · `/teacher/login`
**الطالب:** `/student` (الرئيسية) · `/play/:activityId` (اختيار القالب ثم اللعب)
**المعلم/المالك:** `/teacher/invite/:token` (قبول دعوة) · `/teacher` (الرئيسية) · `/teacher/classes[/:id]` · `/teacher/questions` · `/teacher/activities[/:id]` · `/teacher/arena` · `/teacher/content` · `/teacher/teachers` (المالك) · `/teacher/archive` · `/teacher/settings`
بقية القائمة (التقييم، التقارير، الشهادات، المحتوى، الرسائل) ظاهرة بعلامة «المرحلة التالية» ولا تدّعي العمل.

## 5) الحدود المجانية (تم التحقق منها نوفمبر 2026 — راجع صفحات الأسعار قبل الاعتماد)

**Supabase Free:** قاعدة 500 MB · تخزين ملفات 1 GB · 5 GB نقل شهريًا · 50,000 مستخدم نشط شهريًا · مشروعان نشطان · **يُوقَف المشروع تلقائيًا بعد أسبوع بلا نشاط** · لا نسخ احتياطية يومية.
**Netlify Free:** 300 رصيد شهريًا (نشر، نقل، حوسبة الوظائف، طلبات). عند نفاد الرصيد قد يُوقَف الموقع حتى الدورة التالية.
